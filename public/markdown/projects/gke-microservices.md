# E-Commerce Microservices on Google Kubernetes Engine

## Stack

- GKE
- Java
- Python
- Go
- .NET
- Helm
- Horizontal Pod Autoscaler

## What I Built

I deployed six independent microservices on Google Kubernetes Engine using Helm charts, rolling updates, and Horizontal Pod Autoscaler policies.

## Outcome

- Improved platform uptime by 70%
- Enabled isolated scaling per service instead of scaling the whole application together
- Built a cloud-native environment that reflects real-world distributed application operations
