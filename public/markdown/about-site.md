# About This Site

This portfolio recreates a macOS-style experience in the browser while showcasing Harshal Galande's DevOps background, infrastructure projects, and resume.

It is built with [React](https://reactjs.org/), [Zustand](https://zustand-demo.pmnd.rs/), and [UnoCSS](https://uno.antfu.me/), then customized with resume-driven content for CI/CD, Kubernetes, Terraform, cloud platforms, and observability work.

The goal is simple: make technical experience feel interactive instead of static.
