# CI/CD Pipeline for a Java Spring Boot Application

## Stack

- Jenkins
- Docker multi-stage builds
- GitHub webhooks
- Kubernetes

## What I Built

I designed a webhook-triggered Jenkins pipeline for a Spring Boot app that uses multi-stage Docker builds to keep the image lean and deployment-friendly.

## Outcome

- Improved build reliability by 50%
- Reduced Docker image size by 60%
- Accelerated Kubernetes image pull times across cluster nodes
